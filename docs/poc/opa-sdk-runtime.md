# Embedded OPA SDK runtime qualification

Selected SDK: v1.21.0, commit dc6269f2c648bbbece4b76fa1fc3dbb7b61cc7b6, upstream https://github.com/open-policy-agent/opa/releases/tag/v1.21.0. No standalone OPA service or image is selected.

Linux/arm64, CGO_ENABLED=0, Go 1.27.1: the actual API/Worker/opsctl import closure contains 79 exact Go modules, 2,419 compiled/embedded module files and 1,332 standard library files. Each selected module file is byte-matched to the exact publisher Go zip authenticated by tracked go.sum h1. Archive SHA-256, versions, full Git commits for all modules, file hashes and original notice hashes are locked. All 79 modules retain exact repository/full-commit and publisher archive identities. Eleven older proxy metadata records lacked a full origin; primary publisher commit/tag resolution and byte comparisons against those exact Git source archives close that binding. No checksum is used as a fabricated Git commit.

File assignments retain nested OPA BSD notices, YAML MIT file scopes, klauspost BSD versus gzhttp Apache scope, nested xxhash MIT notices and BSD-2-Clause-Views for go-metrics. No unknown or copyleft license is assigned to the selected compiled source closure. Complete selected source and applicable original notices accompany runtime-go-source.tar; unused tests/docs/assets are not distributed by this archive. Source preparation does not qualify another target or an unselected module.

Actual upstream Rego SDK runs inside the platform policy tests in a digest-locked Linux/arm64 Go container with network=none, pull=never, read-only root and repository/module-cache mounts, a non-root user and GOPROXY/GOSUMDB off. Twelve tests pass with zero skips: trusted publication, bad signatures, deterministic repeated decisions, tenant/scope/Agent/step-up/command gates, forbidden external/nondeterministic builtins, complete decision fields, and compile failure preserving the prior policy. The first attempt failed because its tmpfs was non-executable; retain that raw failure. Only executable isolated /tmp was corrected.

A separate non-root network=none container rebuilds all three Linux/arm64 commands using only this selected source archive, local module replacements and the immutable Go 1.27.1 image, with an empty Go module cache, GOPROXY off and no external mounts for dependency source. Exit 0 demonstrates the selected source closure is rebuildable. It does not establish production Kubernetes compatibility, HA or SP-02 offline reinstall.

The runtime source lock, notice review, offline SDK JSON test log, source-rebuild result and exact source material digest are required together. Drift invalidates this qualification. No patch/fork, provider/LLM, remote OPA download or independent OPA service is introduced. Replacement requires a new signed registry baseline and equivalent fail-closed decision/rebuild/source evidence.
