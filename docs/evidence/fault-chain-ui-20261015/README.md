## 已实现

- 节点选择关联链路；关系显示来源、规则和摘要；健康观测事件定位对应已提交状态与来源步骤，共享路径两端可进入资源详情。
- 规则观察定位持久 QueryResult/Fact，比较值及分子分母、耗时等统计值可打开原 Fact、原值、单位、行列、窗口、结果摘要，再通过已有授权接口读取 Evidence。未匹配本轮关系的统计单独展示，不挂到另一条链路下。
- 缺口按钮直接提交独立 evidence_only 轮次，复用持久 Job、租约、SSE、取消和预算门禁，零模型请求。健康缺口固定 get_resource_health，关系缺口固定 get_dependencies，通信边的统计/覆盖缺口固定 execute_analysis_query（沿用原目标、对端、方向及故障/基线/恢复窗口）。不调用未发布变更或时钟检查。
- 服务端重读并授权原上下文，绑定原轮次、关系摘要、实际存在的缺口、允许的工具及原披露资源。拒绝窗口/目标/工具/关系/父轮次篡改及递归检查；当前范围不足返回错误并进入既有范围编辑器，不扩大权限。
- 检查结果保留原缺口关联，并可独立授权读取原轮次，即使原消息不在当前分页。合格健康快照保留成功 Step 和来源版本并在每次读回时重新校验；没有合格快照明确显示未取得。当前快照不替代历史健康/关系证明，原上下文和缺口不被覆盖。
