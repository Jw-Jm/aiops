# ADR-0038：AI 问数与自然语言排障专项开发

日期：2026-10-12。状态：Accepted（用户授权开发；实现与验收分阶段记录）。

用户在理解《AI 问数与自然语言交互式故障排查实施方案》及无 Incident
资源调查、故障链调查方式后，明确要求“开始功能开发”。据此启动独立 AI
专项，覆盖旧 SP-02 阶段限制；不将本专项等同于 SP-09 完整验收。

## 决定

- 按方案 P0～P6 推进，复用 Go 模块化单体、HolmesGPT、Platform MCP、
  OIDC/OPA、统一持久任务及 Evidence/RCA；不新增 Agent 循环或模型 HTTP client。
- 问数只覆盖平台运维数据；模型提出 QueryIntent，平台执行受控查询并计算数字。
  首批基础代码实现 resources.current 的指定资源类型计数及健康/类型分组。
  尚未实现的数据集不得标记可用；后续扩展目录需增加对应合同与黄金用例。
- 无 Incident 排查使用真实资源身份和独立 ResourceInvestigationContext，
  多义目标先澄清。资源关系不等于因果，调查结果不得自行创建正式故障或 confirmed RCA。
- 会话/Job/Context v3 的持久化、授权、预算、恢复、结果验证完整接通前，
  不启用自然语言任务提交入口。旧 v2 路径与目录保持原语义。
- 两角色无继承，审计与运维授权域分离；人工处置继续本人输入真实 Bash 并确认。
- KubeVirt/CDI/VM/VMI/DataVolume 继续 deferred/disabled/unverified；
  根目录 00～10 正式文档保留。新专项不恢复虚拟化开发。

## 开发与验证范围

本专项从当前本地 platform 工作树开发，保留既有 SP-08 源码与用户文件。
ADR-0037 的远程优先、暂不测试约束针对 SP-08 剩余源码阶段；不据此改动
SP-08 或重跑其业务验收。本专项执行新增模块的单元/合同验证，后续真实模型、
数据库、MCP、浏览器及离线发行验收按各阶段条件开展。

普通会话正文/QueryResult 保留 30 天、首期单授权集群、目录随发行包发布作为
实现默认方向；正式证据和法律保留优先。模型与数据源实际能力、性能预算及
完整评测门槛在对应运行路径开放前冻结，不从接口连通推断质量。

本次授权不包含生产发布、HA、灾备、外部业务数据库、自动修复或依赖升级。
源码、确定性测试、真实运行和正式发行分别报告，不借用旧阶段 PASS。

## 2026-10-12 环境补充

用户明确要求不使用本机 OrbStack。容器、数据库、集群及运行验证操作改到
`192.168.0.63`，登录凭据仅用于会话连接，不写入源码、文档或发行配置。
源码在当前工作树保留可评审变更；本机编译/静态验证不代替远程运行验收。
