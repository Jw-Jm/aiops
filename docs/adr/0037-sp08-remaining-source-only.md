# ADR-0037：SP-08 剩余功能源码继续开发，暂不测试

日期：2026-10-12。状态：Accepted（用户明确授权，源码交付待验证）。

用户在 ADR-0036 阶段收尾后明确要求：“继续，完成 sp08 剩余全部功能开发，但不测试”。因此恢复 SP-08 Task 8.1～8.7 的非虚拟化功能补齐，覆盖上一轮停止页面扩展的决定。本轮不运行组件、Contract、集成、Playwright 或实际业务测试，不运行应用构建、浏览器验收、正式发行或部署。格式化和公共客户端代码生成属于源码维护，不作为验证回执。

新增修改仍首先在 192.168.0.63 的既有远程工作副本完成，再同步本地并提交既有草稿 PR。根目录 00～10 正式文档只读。不得把上一阶段的测试通过记录用于本轮新源码，也不得宣称 SP-08 运行验收已完成。沿用 ADR-0034 的独立只读源码审核，问题仅由源码核对修正，本轮不复测。

补齐范围：资源图谱的逐节点查询、方向/类型/深度/节点预算与 URL 条件，冻结 RCA 与当前图谱区分，管理发布/激活/回滚前真实版本和作用域引用预览、实际绑定 revision 确认，签名执行配置的发布前执行边界核对，后检查后的证据和根因复核入口。API 仅新增兼容的可选策略 logicalName 筛选，重新生成客户端；不新增依赖，不引入模型自动执行权限。

OIDC 内存 token、operator/platform_admin 无继承、人工实际命令初始为空、本人确认、签名与 expectedRevision 约束继续有效。KubeVirt/CDI/VM 保持 disabled/unverified；无 BMC 硬件真实验收仍延期。SP-09、HA、灾备、一般容量扩容不在范围内。数据库、PV、身份、密钥、归档和恢复材料保持；ADR-0035 只适用于已经授权的测试环境调整。

后续测试、界面及实际业务复审、正式发行准入、统一部署与最终验收均尚未执行；需恢复验证阶段后完成，不能以源码交付替代。
