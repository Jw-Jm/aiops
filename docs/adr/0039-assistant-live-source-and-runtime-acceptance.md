# ADR-0039：助手真实来源与运行机制验收

日期：2026-10-13。状态：Accepted（用户明确授权）。

用户要求完成下一步第 2、3 项：真实采集/来源验证和运行/恢复/真实 OIDC API
浏览器闭环，并明确“模型回答质量不作为验收标准”。

本轮以真实采集标签、UID、事件时间、来源 revision/绑定/证明、有限范围容量，
以及会话授权、任务幂等/并发、取消/晚到结果、撤权、预算、超时和进程崩溃接管
为验收依据。实际模型/MCP 协议与平台结果校验仍须有效；不要求模型回答的
问数成功率、排障帮助率或人工质量评分达标。既有五例质量 FAIL 原样保留，
不能改为质量 PASS，但也不阻断本轮机制验收。

运行限 root@192.168.0.63，使用专属 canary namespace、任务目录、数据库、
来源及 OIDC 身份隔离；现有 core/final 组件只读核对，不以本次测试升级生产
镜像、修改旧阶段数据或重新开展 SP-08 全产品验收。新来源的结论限实际
采集/测量过的目标与时间窗，不能扩大到所有生产集群/namespace。

KubeVirt/CDI 继续延期，根目录 00～10 正式文档只读。DeepFlow 维持当前
Profile/来源边界：核对并报告是否有实际 Server/Querier/Agent；未部署的
来源不标记 live 或通过，不用 Fixture 代替 eBPF。正式发行、生产切换、依赖
升级、HA/灾备和自动修复仍不在本轮授权范围内。
